# Nikdoof Tap

## How do I install these formulae?

`brew install nikdoof/tap/<formula>`

Or `brew tap nikdoof/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "nikdoof/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
